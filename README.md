# Prompt Pad

一个纯本地的 Chrome 提示词管理扩展（Manifest V3）。把常用提示词一键填进 claude.ai、chatgpt.com、gemini.google.com 等页面的输入框。

- **纯本地**：数据只存在 `chrome.storage.local`，不发任何网络请求。
- **中文界面**，浅色 / 深色跟随系统。

## 安装

1. 下载或 `git clone` 本仓库到本地。
2. Chrome 地址栏打开 `chrome://extensions`。
3. 打开右上角的 **开发者模式**。
4. 点击 **加载已解压的扩展程序**，选择本仓库目录（包含 `manifest.json` 的那一层）。
5. 建议把 Prompt Pad 固定到工具栏（拼图图标 → 📌）。

更新代码后，在 `chrome://extensions` 中点扩展卡片上的 ↻ 重新加载即可。

## 使用

| 操作 | 说明 |
| --- | --- |
| 打开弹窗 | 点工具栏图标，或按 **Alt+P**（可在 `chrome://extensions/shortcuts` 修改） |
| 搜索 | 弹窗打开后直接输入，匹配标题、内容、标签；↑ ↓ 选择，Enter 使用 |
| 分组标签 | 顶部标签条按标签筛选；编辑时用逗号或空格分隔多个标签 |
| 置顶 | 条目右侧 📌 按钮，置顶的条目排在最前 |
| 填入 | 点击条目 → 全文插入当前页面**聚焦的输入框**（textarea / input / contenteditable）末尾，光标放在末尾，弹窗自动关闭 |
| 复制兜底 | 页面没有聚焦的输入框（或是 `chrome://` 等受限页面）时，自动复制到剪贴板并提示 |
| 新建 / 编辑 / 删除 | 「＋ 新建」；条目右侧 ✎ 编辑；🗑 删除（再点一次「确认删除」） |
| 变量 | 内容里写 `{{变量名}}`，使用时会弹出小表单填写；同名变量只填一次，上次填过的值会自动带出 |
| 右键保存 | 在网页上选中文字 → 右键 **保存选中文字为提示词**，保存成功时图标上会闪一下 ✓ |
| 导入 / 导出 | 弹窗底部。导出为 JSON 文件；导入会在新标签页中进行（弹窗打开文件对话框会被关闭） |

> 提示：使用前先在目标网站的输入框里点一下，让它处于聚焦状态，再按 Alt+P 选择提示词。

### 导入 / 导出格式

```json
{
  "app": "prompt-pad",
  "version": 1,
  "prompts": [
    {
      "id": "可选，同 id 会覆盖",
      "title": "标题（可省略，默认取内容第一行）",
      "content": "提示词全文，可含 {{变量}}",
      "tags": ["开发"],
      "pinned": false
    }
  ]
}
```

也可以直接导入一个提示词数组。导入规则：同 `id` 覆盖；标题和内容都相同的跳过；其余追加。

## 预置示例

首次安装会写入 3 条示例（标签「示例」）：

- **看待办** — 查看项目待办并按优先级列出。
- **按 docs/TASKS/<版本>.md 做** — 带 `{{版本}}` 变量，按任务文件逐项实现。
- **继续** — 就是「继续」。

## 文件结构

```
manifest.json      扩展清单（MV3）
background.js      Service Worker：首次安装写入示例、右键菜单
popup.html/css/js  弹窗界面（在标签页打开时即管理页）
lib/store.js       数据读写、变量解析、导入合并
lib/inject.js      注入页面的插入逻辑（兼容 ProseMirror / Quill / 原生输入框）
icons/             图标
```

## 权限说明

| 权限 | 用途 |
| --- | --- |
| `storage` | 本地保存提示词 |
| `activeTab` + `scripting` | 仅在你点击图标 / 右键菜单时，向当前标签页注入插入文字或读取选区的脚本 |
| `contextMenus` | 右键「保存选中文字为提示词」 |
| `clipboardWrite` | 无输入框时复制到剪贴板 |

不申请任何站点的常驻访问权限，也没有内容脚本常驻页面。
